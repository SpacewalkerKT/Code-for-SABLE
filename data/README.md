# Data

The processed CSV files in this directory are used by the documented SABLE execution workflow.

## Files

- `common_data.csv`: processed traffic-volume sequence records used for episodic task construction.
- `incident_data.csv`: processed incident-associated records and task metadata.

## Source

The data were prepared from the traffic and incident sources described in the accompanying manuscript and dataset record:

IEEE DataPort DOI: 10.21227/d6ht-c375

## Usage

The default configuration expects these files under the `data/` directory. Their column structure and preprocessing assumptions are documented in the repository README and source code.

The software license in this repository applies to the source code. Data use remains subject to the terms of the cited data sources and dataset record.
